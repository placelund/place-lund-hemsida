## Required Images

### Hero Section
- **hero-placeholder.jpg** (1920x1080px or larger)
  - Main hero image for the homepage

### Property Selection Cards
- **hotel-placeholder.jpg** (800x600px or larger)
  - Image representing traditional hotel rooms
  - Should showcase hotel rooms with full service amenities

- **hotel-studio-placeholder.jpg** (800x600px or larger)
  - Image representing compact hotel studio rooms
  - Should showcase modern studio-style hotel rooms with kitchenette

- **studio-apartments-placeholder.jpg** (800x600px or larger)
  - Image representing self-contained studio apartments
  - Should showcase full apartment interiors with kitchen

## Image Guidelines

- **Format:** JPG or PNG
- **Quality:** High resolution for best results
- **Aspect Ratio:**
  - Hero: 16:9 (landscape)
  - Property cards: 4:3 (landscape)
- **File Size:** Optimized for web (under 500KB if possible)
- **Naming:** Use lowercase with hyphens (as shown above)

## Adding Images

1. Add your images to this directory: `/public/images/`
2. Ensure filenames match exactly as listed above
3. The Next.js image optimization will handle responsive sizing automatically
