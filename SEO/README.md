# SEO Documentation Folder

## Purpose

This folder contains specialized SEO guidelines and requirements that supplement the general SEO strategy outlined in `/rules.md`.

## ⚠️ CRITICAL: When to Read This Folder

**BEFORE making ANY of the following changes:**

1. Creating or modifying page content
2. Writing or updating meta tags, titles, descriptions
3. Adding or changing headings (H1-H6)
4. Creating or editing image alt text
5. Modifying URLs or internal links
6. Adding schema markup
7. Writing any user-facing text
8. Creating new pages or sections

**Note:** Final SEO quality check will be performed after development is complete.

## What Goes in This Folder

### Recommended Documents:

1. **Keyword Research**
   - Primary, secondary, and long-tail keywords per page
   - Search volume and competition data
   - User intent analysis

2. **Competitor Analysis**
   - Competitor keyword strategies
   - Content gaps and opportunities
   - Backlink analysis

3. **Technical SEO Requirements**
   - Schema markup templates
   - Structured data requirements
   - Page speed optimization guidelines
   - Mobile optimization checklist

4. **Content Optimization Guidelines**
   - Word count requirements per page type
   - Keyword density targets
   - Content structure templates
   - Internal linking strategy

5. **Local SEO Strategy**
   - Google Business Profile optimization
   - NAP consistency requirements
   - Local citation guidelines
   - Location-specific content requirements

6. **Link Building Strategy**
   - Internal linking structure
   - External link acquisition plan
   - Anchor text guidelines

7. **Page-Specific SEO Requirements**
   - Individual page optimization checklists
   - Unique keyword targets per page
   - Conversion optimization notes

## How to Use This Folder

### Development Workflow:

1. **Read `/rules.md` first** - General project rules and SEO strategy
2. **Read ALL documents in this `/SEO/` folder** - Specific SEO requirements
3. **Read relevant `/docs/` file** - Page content specifications
4. **Make changes** - Following all guidelines from above

Final SEO quality check will be performed after development is complete.

### Compliance Requirements

**All content must comply with:**
- General SEO Strategy in `/rules.md`
- Specific guidelines in this `/SEO/` folder
- Page-specific requirements in `/docs/` files

**Non-compliance results in:**
- Poor search engine rankings
- Lost organic traffic
- Reduced conversion rates
- Costly rework

## Adding New SEO Documents

When adding new SEO documentation to this folder:

1. **Use descriptive filenames:**
   - `keyword-research.md`
   - `competitor-analysis.md`
   - `technical-seo-requirements.md`
   - `local-seo-strategy.md`

2. **Keep documents focused:**
   - One topic per document
   - Clear, actionable guidelines
   - Easy to reference during development

3. **Update this README:**
   - Add new document to the list above
   - Describe its purpose
   - Note when it should be consulted
